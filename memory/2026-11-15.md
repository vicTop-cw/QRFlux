### 2. wasm 浏览器引擎三条路线全部实测受阻（结论记录）

| 路线 | 阻碍 |
|---|---|
| wasm (MVP) | String 无稳定 ABI；core 无取线性内存指针 API（`to_ptr/from_ptr` 均不存在） |
| wasm-gc | host 须提供 75 个 non-null `(ref extern)` 全局（js_string_constant），JS API 的 nullable `anyref/externref` 类型不匹配，4 种组合（mutable × 类型名）全部被拒 |
| js 后端 | ESM 可加载可调用，但长输入解码返回静默错值（`ok:true` + 内容乱码）——已提 issue #2527 |

**性质**：构建上下文相关的产物差异（同代码 `moon test --target js` 全绿、native 正确）。应用层假设已全部排除：release 优化、base64 实现（core/自研）、迭代器 vs 索引、字符串边界（全长遍历统计一致）、Buffer 大量写入（11088 字节逐字节校验）、位运算（内联最小实现）、跨包短调用、跨包长字符串统计。
