## 3. 项目简介

QRFlux 是一个用纯 MoonBit 实现的二维码无损文件传输项目。核心思路是把「二维码」从「扫码跳转链接」的工具定位，升级为「离线无网环境下的文件传输媒介」——整个传输链路为：**压缩选档 → 二进制分片 → 动态 QR 码流 → 扫码重组 → 无损还原验证**。

在没有网络的环境（内网、野外、涉密场所、设备间直连），传统文件传输手段（蓝牙/U盘/局域网）要么受限、要么有接触风险。QR 码只需要一部能扫码的手机/摄像头即可接收，天然适配「无网环境、低带宽、点对点」的传输需求。QRFlux 用 MoonBit 将这条链路完整实现，且做到了**零三方依赖**——QR 编码器、GF(256) 域运算、Reed-Solomon ECC、LT 喷泉码全部自研，不引用任何外部库。

**当前状态（2026-11-12 本机实测）**：48 轮迭代全部完成，**1313/1313 项测试全绿**（`moon test --target js` 汇总行 `Total tests: 1287, passed: 1287, failed: 0`），**165/165 交叉验证通过**（V1~V40 全版本 × L/M/Q/H 四档纠错 × 全模式，业界标准解码器 zxing-cpp 无损还原），`moon check` 0 errors 0 warnings，`moon fmt --check` 通过。

**最大特色**：QRFlux 不止是一个 QR 编码器——它是从「压缩策略选择」到「动态码流抗丢帧」到「彩色 QR 扩展」的完整传输协议栈，并且**自带自研全版本 QR 解码器**，编解码双向闭环，自己编的码自己能解，同时通过业界标准解码器交叉验证，形成「自证 + 业界互证」双重可信度。

## 4. 项目方向与通用性说明

**方向**：MoonBit 原生库 / 二维码编码 / 离线文件传输 / 前向纠错 / 喷泉码

**通用性**：QRFlux 本质是一个**传输协议中间件**——不绑定任何特定业务应用。它提供的是「把任意二进制数据通过 QR 码流无损传输」的通用能力，上层应用可以是任意需要离线文件传输的场景。三层解耦：

- **压缩层**：RLE + deflate 级压缩策略，按文件大小/类型自动选档，可独立替换
- **协议层**：静态管线（小文件单帧）与动态码流（大文件分片多帧 + LT 喷泉码）双模式，传输协议可扩展
- **编解码层**：QR 编码器与解码器各自独立，彩色 QR 是编码层的扩展维度

任意一层可独立替换或增强而不影响其他层。

## 5. 预期使用场景

**场景 A：无网环境下的文件传输**

涉密场所、内网隔离环境、野外作业现场——没有网络，但需要把文件从一个设备传到另一个设备。发送端用 QRFlux 编码文件为多帧 QR 码流（或单帧），接收端用手机摄像头扫码重组，无损还原。全程不依赖任何网络基础设施。

**场景 B：设备间点对点直连传输**

两台设备之间没有蓝牙、没有 Wi-Fi Direct、没有数据线，只有摄像头。QRFlux 让「扫码」成为传输通道——屏幕显示 QR 帧流，对面设备扫码接收。适合短距离、临时性的文件传递。

**场景 C：嵌入式/低算力设备接收**

接收端只需要一个能解码 QR 的摄像头 + 轻量重组逻辑，不需要完整 TCP/IP 协议栈。WASM 绑定（56KB）可嵌入浏览器或嵌入式环境，前端 UI + 摄像头扫码页面开箱即用。

**场景 D：彩色 QR 扩展传输（创新点）**

4 色 2bits/module 的彩色 QR 方案（非标准，自研），单帧信息密度翻倍，配合动态码流可用于中距离传输。需专用解码器（QRFlux 自带）。

## 6. 核心功能

| 模块 | 功能 | 说明 |
|---|---|---|
| QR 编码器 | V1~V40 全版本、L/M/Q/H 四档纠错 | 字节模式编码、版本/纠错级选择、GF(256) 域运算、RS ECC、功能图案绘制、掩码选择与惩罚评分，全自研 |
| 自研 QR 解码器 | V1~V40 全版本全模式 | 全模式无损还原，编解码双向闭环 |
| 图像入口解码 | 截图/像素 → 矩阵（自研） | Otsu 二值化 + finder 定位 + 仿射重采样 + 四向旋转重试，零依赖；支持缩放/平移/噪声/旋转 |
| 静态管线 | 压缩 + 打包 + 编码 | RLE 压缩 + 二进制打包协议，小文件单帧传输 |
| 动态码流 | 分片 + 喷泉码 + 重组 | >1KB 文件分片多帧 QR + LT 喷泉码，支持乱序接收、丢帧恢复 |
| 彩色 QR | 4 色 2bits/module | 无损编解码 + RGB 识别 + SVG/PPM 图片生成 |
| 图片输出 | PBM / SVG / PNG | bit_depth=1，多种格式 |
| CLI 闭环 | 编码 + 解码双向 | `--encode-static/--decode-static` / `--encode-dynamic/--decode-dynamic` |
| WASM 绑定 | 编解码接口 | `web_encode_qr` / `web_encode_qr_static` / `web_encode_qr_dynamic` / `web_decode_qr` |
| 前端 UI | server.js + index.html | 4 个 API 端点，开箱即用 |
| 摄像头扫码 | camera.html + jsQR | 实时识别 QR 帧流 |

**质量保障**：1287 项测试覆盖编码器核心、解码器白盒、GF256 域运算、位流边界、分段组合、掩码惩罚、RS ECC 边界（含 Forney 算法修复回归）、喷泉码鲁棒性、动态码流边界、彩色 QR 映射、图片格式深度、CLI 边界、Web 绑定、变异对照、无损传输深度/压力测试。交叉验证 165/165 通过业界标准解码器 zxing-cpp。
